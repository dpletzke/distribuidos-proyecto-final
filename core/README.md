# core

El backend de mascotas está en [petalert-mascotas-service](petalert-mascotas-service/README.md), implementado con Express y TypeScript.

Para instalar el proyecto desde cero siga la [guía de inicio](../README.md). Desde la raíz, `docker compose up -d --build` levanta todos los servicios; la API de mascotas queda en http://localhost:3000/api/mascotas.

La recepción de eventos de collares queda para otra fase.
